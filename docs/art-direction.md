# Lofi Room · 美术方向 v0

阶段：Phase 0 立项。以下为下一阶段的制作基准，尚无模型或渲染验收。

## 核心画面

2026 年秋天，17:20。有人刚离开书桌，Mac 上还有没写完的文字，杯子冒热气，电视在安静播放，窗外树叶轻摇。视觉重心是桌面上的米色 Macintosh；CRT 与窗户构成另外两个支点。先把这一刻做精致，再扩展昼夜与四季。

微缩手办感，中低面数、柔和倒角、低饱和材质。生活痕迹来自杯渍、错落的磁带标签和随手搭着的耳机，避免靠堆满道具制造细节。不要像素风、强霓虹或过量 bloom。

## 构图与尺寸草案

房间约 4.2 × 3.6 × 2.8 米。Blender Z 向上，桌高 0.75 米；导出后由 glTF 转为 Y-up。

- 主视角：开放前侧的 3/4 微俯视，窄视角透视，桌面占视觉中心，保留前景地毯作为呼吸空间。
- 后墙左侧窗户，下方书桌与 Mac；右侧低柜放 CRT，Mac—窗—CRT 形成三角。
- 床沿右墙后退，书架靠后墙；窗外树置于独立景深层，不遮住全部天空。
- Phase 1 输出全景、桌面近景、窗边三个 Eevee 候选。推荐全景作默认机位，后两者作预设。
- 默认相机固定构图，仅允许厘米级漂移；自由 OrbitControls 仅供开发检查。

## 光照与材质

主光用实时太阳/月亮方向光；窗框和百叶窗实际参与投影。室内暖灯与窗外冷色形成明暗层次，夜间保留可读的暗部。Blender 灯光用于预览，网页灯光单独实现。

Phase 1 只验证主光、环境补光和时刻滑块。Phase 3 再烘焙 AO 与关键时刻间接光图集，运行时线性混合，避免烘焙太阳直射后与实时阴影重复。先完成秋季四时刻，再拓展四季。

Principled BSDF 为统一材质入口，命名 MAT_*。硬表面使用按真实尺度控制的 Bevel；织物哑光，ABS 微粗糙；CRT 使用微凸玻璃及独立屏幕面。果冻键盘在精修阶段验证 transmission 成本，低画质提供简化材质。透明材质按本机 Blender 导出器实际支持的属性设置，不照搬旧版 blend_method API。

ACES、克制发光 bloom、轻暗角与细颗粒；所有后期都需可随画质降低。屏幕使用独立 CanvasTexture，不使用外部影视素材。

## 技术预算与边界

- 本项目更严格的总预算：应用修改器后 < 80k 三角面，draw call < 150，纹理 < 64MB。
- 1440p 核显 60fps 是待实测目标，不能以构建通过代替性能验收。
- 不引入远程模型、音乐或付费素材；原创 3D 内容均来自 Blender 源文件与构建脚本。
- Blender 使用本机 5.2.1 LTS；保留现有根目录 Vite 工程，不再创建第二套 /web。
- Phase 0 不修改当前 Blender 场景。Phase 1 通过连接检查后，从空场景开始创建标准 Collections。
