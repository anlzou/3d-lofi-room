# Phase 2 造型与材质交付

2026-09-06，包含最新一轮用户反馈。主家具布局和网页全景相机参数保持原样；仅调整小物接触关系和特写机位。

## 最新反馈已落实

双抽屉补齐，上抽屉拉开约 18 cm，内有相片收纳盒、两片磁带和三张照片；桌面另放两片磁带。电话听筒两端朝同一方向，PS 手柄改为连续握柄轮廓，连线改为有下垂与缓弯的单根软线。两只 Fumo 改为大头、短身、双腿朝前的坐姿，以不同角度朝向电视；造型参考 [Gift 官方 Fumo 产品说明](https://www.gift-gift.jp/nui/nui1274.html)，没有使用其商品贴图。

绿枕头落回床垫，熔岩灯底座完整落在书架上。掌机所有按钮和屏幕统一跟随机身倾角，增加电池盖、扬声孔、Start/Select 与卡带细节。猫的头身尾合为平滑连续曲面，保留手办风格，不使用毛发片；毛绒材质仍为简化表达。电视旋钮改为嵌入机壳侧面板的旋钮，天线不再投出误读成电线的硬阴影。移除压到拖鞋的矩形堆，只留两本有纸页的杂志移到旁边；床上漫画保留。白色机甲旁新增小仙人球，原风扇和白枕头未改。

新增验收近景：[双抽屉与内容](../blender/renders/phase2-feedback-bedside.png)、[坐姿 Fumo 与落地灯座](../blender/renders/phase2-feedback-plush.png)。

## 本轮结果

- Compact Macintosh 的厚贝塞尔、软驱、提手与凸面玻璃；果冻键鼠有简化电路和两枚 LED。
- 电话重做整齐 3×4 按键、听筒叉架和接回机身的卷线；耳机有头梁、耳罩与转轴，缩减设备连线为五根。
- 重做前后网罩、扭转叶片、俯仰关节和底座按钮；`ANIM_fan_blades` 在网页慢转，`ANIM_fan_head` 保留。
- 叶片有弯曲轮廓、叶脉、茎与盆土连接；两朵花各有独立花茎。修正窗台小鸟与盆栽、桌面杯碗/便签/设备之间的接触关系。
- 猫保留圆垫睡姿，增加耳、口鼻、闭眼、爪和环身尾，条纹直接分配到表面。床品改为压痕枕头和大褶皱被子；棉拖鞋有鞋底、鞋面与开口。
- CRT 使用原创像素场景；PS1、手柄和线、VCR 与 DVD 在电视柜内叠放。新增两只窗台机甲、两只书架 Fumo、六块积木、Game Boy 和半抽卡带。
- 地球仪有海陆色块、子午环和支架。水壶具有独立壶嘴、把手、盖与盖钮。床头柜增加微开抽屉相片边和小相框，红光七段闹钟跟随房间时刻。
- 三张原创有限套色网点海报；两张裸碟使用简化彩色反射带。墙、地板、木材、布、米色塑料、玻璃、猫橘色及屏幕/炉丝发光采用统一色板。
- 猫头 `SOCKET_emoji_cat` 对应三枚奶油色半透明 2D Z，缓慢呼吸显隐。未加入点击、四季、天气或事件系统。

## 验证与边界

- 源场景 1,041 个对象，导出 78,338 三角面；无负缩放，灯光/相机位于指定 Collection 并排除导出。
- `EXPORT_OK`，GLB 3,153,412 字节；35 个必要挂点、28 个七段数字片及 3 张内嵌图通过 `node scripts/verify_glb.mjs`。
- `npm run build` 与 TypeScript 检查通过。Vite 提示主 JS 632.67 kB 超过默认 500 kB 提醒阈值，后续优化阶段处理。
- 实际网页加载成功、控制台 error/warn 为空；17:20 / 00:00 / 23:59 时间控件验证，风扇与 3 个 ZZZ 已接入。默认全景静止帧 115 draws，阴影刷新帧会更多；此数值不是帧率承诺。
- 完整 `build_phase2.py` 后台重建通过（78,530 面）；随后删除两处合计 192 面的饰边，最终源文件/GLB 检查均为 78,338 面，重建脚本已同步删除步骤。原 Phase 1.5 与本轮反馈前的 `.blend` 备份保留；材质与原创贴图已打包。
- MCP 视口截图返回黑图，本轮以真实 Cycles 渲染和网页截图完成视觉检查。尚未进行全屋 lightmap 烘焙或最终设备性能验收。

## 取舍

没有加第三个机甲、声卡和额外零食袋，避免挤占摆件与设备空间。旧抽象手办和重复灰积木被成品替换；电话卷线保留并连接听筒，避免孤立“弹簧”。未额外加入清单之外的陈设。窗外延续既有三栋低细节房屋布局，没有扩建城市。

逐对象优先级、阶段和三角面见 [资产清单](asset-list.md)；机器可读版本为 [manifest](phase2-manifest.json)。
