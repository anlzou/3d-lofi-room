# Phase 1.5 布局加密验收记录

2026-09-05。本轮停在灰模布局阶段，未进入正式材质、UV 烘焙或 Phase 4 屏幕内容系统。

## 结果

- 35 组资产；源场景 487 个对象（含相机、灯光和 Empty）；GLB 477 个节点。
- 55,408 三角面，预算 80,000；GLB 3,313,648 字节，内嵌一张原创测试卡。
- CRT 与柜体整体缩小 18%，移到左前，最终旋转 35°；主机位推进 12%。桌面高 0.72m，Mac 高 0.34m；椅子横向放大 14%，床整体抬高 0.08m。
- 桌面电子设备、生活杂物、六根设备线、电话盘线、游戏手柄线已摆放；右墙有上层收藏架、中层海报软木板挂钟、下层书柜滑板；床有起伏被子、抱枕和漫画。
- 前景植物和唱片箱、中景设备、窗外房屋/围栏/电线杆形成纵深；植物经第二轮调整避开电视屏幕。当前前景物件完整可见，没有采用画框边缘裁切。
- 四块 EMIT_screen 使用纯发光测试卡；全部指定季节占位、四个猫挂点、雨/花瓣/蒸汽挂点、灯具路径已建立。全季节同时显示只用于布局审核。

## 取舍与新增

提示词允许的备选中，选择落地植物、滑板、熔岩灯、泡面碗，未另做鱼缸、吉他、霓虹牌或零食袋，避免重复占地。照片、票根、便签先共用纸片灰模表现，正式图案留到 Phase 2。新增唱片收纳箱、床下收纳盒、地毯翘边。没有为省面数删除清单必需物件；网页运行时按材质和最近的语义父级合批，源模型仍保留独立对象。
