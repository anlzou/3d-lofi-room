# 世界状态与事件设计

本文件为 Phase 4 契约，Phase 0 只建立类型与默认值。

单一 WorldState 保存季节、0–24 小时时刻、天气、自动模式、展示模式、音量与机位。设备状态独立放在其 devices 字段；动画只修改派生表现，不反写时间、季节等源状态。目标状态与过渡中的视觉状态分离，默认 5 秒过渡。

## 天气合法性

| 天气 | 春 | 夏 | 秋 | 冬 |
| --- | --- | --- | --- | --- |
| clear / cloudy / overcast | 是 | 是 | 是 | 是 |
| drizzle / rain / windy | 是 | 是 | 是 | 是 |
| storm | 低概率 | 午后至夜间优先 | 低概率 | 禁用 |
| fog | 清晨优先 | 低概率 | 清晨优先 | 清晨优先 |
| snow | 禁用 | 禁用 | 禁用 | 是 |

优先条件影响自动模式权重，不禁止合法的手动选择。换季时非法天气归一为 cloudy，并轻提示；归一后再保存。天气、灯色、天空、风力、粒子发射速率在 3–8 秒内插值；已有粒子自然消亡，专属模型不能突然闪现。

自动模式按本地日期选季节并跟随本地时钟；手动时间或季节操作退出自动模式。手动模式的时间以每真实秒推进六分钟（一小时六秒）的固定速度前进；后台暂停 RAF 与音频，恢复时自动模式重读时钟，手动模式不补算后台经过时间，避免事件集中爆发。

展示模式（按钮在时刻下方的按钮栏）让房间自己过日子：开启时自动流动时间，并按 `showcaseAt(hour, season, weather)` 的分段作息布置设备——起床→晨间→上午工作→午休→下午工作→傍晚回家→夜间→深夜阅读→准备睡觉→深夜安睡。路灯、串灯与熔岩灯不看作息，只看太阳高度（`daylightAt` < 0.35，约 17:57 亮、06:08 灭），串灯在展示模式中由 `showcaseStrip` 接管为彩虹 + 顺序点亮（每颗灯泡各占色轮一段，色相缓缓流动，选中的颜色作为彩虹起点；用户已设的节奏保留，停着则给 1 圈/秒），退出时还原用户自己的串灯设置。暖炉、风扇与窗户按季节和天气推导。每段只在切换时应用一次，因此同一段内手动改动会保留到下一段；关闭展示模式交回手动控制，并把「时间流动」恢复为开启前的状态。

默认状态（`createDefaultState`）是展示模式开启、时间 11:30：首次访问就是一个正在过自己日子的上午房间，载入时 `setShowcase(true, false)` 会自动开始时间流动，`index.html` 里的时刻滑块、时钟与时段文案也按 11:30 写好，避免模块执行前闪一下旧值。已保存的设置仍然优先；`showcase` 只接受布尔值，非法值回落到默认值 `true`。

载入流程（`loading.ts` + `main.ts`）：模型与五张光照贴图是独立下载，两边同时开始并共用一个进度条；模型用 `fetch` + `response.body.getReader()` 流式读，既能报真实字节数（不依赖服务器是否给出 Content-Length，没有就用磁盘上的标称体积），也能在 Draco 解码前 `await` 一帧把进度画出去。进度按体积加权：模型 2.76 MB、光照贴图 2.62 MB、解码与布置各给一个小标称值。左下角（状态栏位置）显示「正在加载… / 百分比 / MB」，超过 12 秒没有新字节就提示网络较慢，超过 45 秒出现「重试 ↻」（任何时候失败也会出现，点击重载页面）。失败不会留下空白房间：捕获到的错误写入状态栏并标红。`index.html` 里还预加载了模型与五张光照贴图：`crossorigin` 必须与消费它们的加载器一致（模型是 `fetch`、贴图是 three 的 `ImageLoader`，即 `anonymous`），否则浏览器会各下载两遍而不是复用预加载。

渲染清晰度与开销由 `perf-governor.ts` 双向自适应：基础比率 `pixelRatioFor` 取设备像素（封顶 1.5，大屏再按 2.6 MP 起步预算收缩），运行时缩放系数在 `0.62–2` 之间升降——连续 3 帧超过 20 ms（单次卡顿如切换标签、上传贴图不算）才降一档（×0.85）并把这次的高度记为上限；平均低于 17 ms（60 Hz 一帧 16.7 ms，所以「有余量」的阈值就落在刷新间隔之下）就升一档（×1.15）；两次调整之间分别有 1.5 秒 / 1.2 秒冷却，前 90 帧（着色器编译）不参与判断。上限不会永久钉死：连续 30 秒舒适后每次允许回升 0.1，最多回到满值。也就是说机器吃得消时会渲染到 2 倍基础比率即超采样，这正是消除细小物件锯齿的地方，但 `bufferRatio` 不会超过 4.2 MP 的清晰度预算，大屏也不会白烧像素。改比率只换绘图缓冲（`setSize(..., false)`），画布 CSS 尺寸不变、不重新布局，且判断放在 `render()` 之前，避免 present 之后重分配缓冲导致的空帧。模型自带的贴图在载入时把各向异性拉到 4，斜视角下木地板与墙面不再糊。光源：阴影改用 `PCFSoftShadowMap`（软滤波避免太阳阴影边缘在两次重建之间爬行），太阳图 1024² 配 `normalBias = .02`。另外时钟数字、时段文案与滑块只在分钟真的变化时写 DOM。

展示模式还会带着日历一起走：`crossedMidnight(previousHour, hour)`（前一时刻 > 20 且新时刻 < 4）判定跨日，新的一天由 `nextShowcaseDay(season, weather, roll)` 决定——季节按春→夏→秋→冬顺序进一位，天气从该季节合法的备选里随机抽一个（排除当前天气，所以每天都能看出变化；雪只在冬天、冬天不出雷雨）。跨日时会强制重算一次作息，因为暖炉、风扇与窗户取决于季节；状态栏会播报`新的一天 · 冬 · 炉火 · 窗外：雪`。`roll` 由调用方传入，随机性留在 main.ts，纯函数可测。

串灯外观由 `strip` 字段描述：`color` 决定基色与饱和度，`blink` 是节奏（Hz，0 为常亮），`chase` 让亮点逐个跑过，`cycle` 让色相随时间旋转，`rainbow` 让每个灯泡各占色轮上一段。彩虹用 `rainbowHue(baseHue, phase, drift)` 取色：第一颗灯泡是选中的颜色，往后每颗沿色轮前进，总跨度 `rainbowSpread = .85`，所以相邻灯泡自然渐变；与 `cycle` 同时开启时整条彩虹缓缓流动。开启彩虹会自动带上顺序点亮和自动变色，好让效果立刻可见。

灯光开关与灯光输出分离：`devices` 里的布尔值是逻辑状态，面板开关与点击交互立即翻转；实际亮度另外乘以 `light-fade.ts` 的缓动值（0–1，`exp` 缓动，帧率无关）。点光源强度、灯罩/灯管自发光、串灯灯泡、屏幕自发光与暖炉线圈都用同一个缓动值，因此不会出现灯罩先亮而房间还暗的错位。展示模式用慢曲线（约 4 秒到 90%，读起来像天色渐暗），手动点击用快曲线（约 0.3 秒），载入时缓动值直接取当前开关状态，避免刷新时房间从全黑淡入。

太阳阴影用 `sun-shadow.ts` 的 `sunShadowClock` 控制重建时机：`shadowAngleStep = 0.0035` rad（约 0.2° 太阳行程，在主机位约 1.4 像素）保证每一步都看不出跳变，`shadowMinInterval = 1/24` 秒是上限保护（拖动时刻滑块时不会把帧预算全花在阴影上）。太阳高度接近地平线（`daylight ≤ .05`）时不重建，天亮后第一次检查必然重建。太阳与台灯各自的 `shadow.autoUpdate` 都关掉，逐帧的太阳重建只设 `sun.shadow.needsUpdate`，跳过台灯那张 512² 阴影图；只有换灯或场景变化才由 `refreshShadows()` 一次重建两张。

设置存 localStorage，带 schemaVersion；读取进行类型、范围和天气合法性校验。URL 参数 season/time/weather 覆盖已保存值。损坏存储回到默认值；读写失败不阻断画面。

## 交互与声音

1–4 切季节，左右箭头调时刻，Space 暂停时间，F 全屏，H 完全隐藏 UI，M 静音。焦点在输入框时不拦截其按键；隐藏 UI 后 H、双击画面或双击触摸屏任意位置均可恢复，Esc 关闭面板。音频默认关闭，用户明确开启后创建 Web Audio 图，默认主音量 0.12，无旋律。

## 事件调度

随机间隔 30–150 秒，事件带权重、独立冷却、互斥设备锁及合法条件。每次只播放一个显著事件；常驻微动独立。固定种子用于验收复现，后台停止调度。

| 事件 | 条件 | 冷却 |
| --- | --- | --- |
| Mac 弹窗 / 打字 | Mac 醒着 | 120 秒 |
| CRT 短暂跳台 | 电视开启 | 180 秒 |
| 猫伸懒腰 | 猫空闲、非深夜 | 180 秒 |
| 风动便签 | 窗开、风力足够 | 150 秒 |
| 鸟落窗台 | 白天、非暴雨 / 雪 | 300 秒 |
| 暖炉水壶热气增强 | 冬、暖炉开启 | 120 秒 |

猫状态：Sleep → Stretch → WatchWindow → Sleep；后续再加入 Walk / Desk / Heater。切换季节只改变行为偏好，不瞬移。抚摸可触发回头或继续睡，声音受统一静音控制。

## 验收边界

Phase 1：真实 GLB 加载、阴影、时间滑块、浏览器无错误。Phase 4：完整秋季昼夜、合法天气、屏幕、环境音、事件及核心交互。Phase 5：四季矩阵、连续昼夜截图、3 分钟生命感观察、2 小时内存观察及指定硬件帧率测试。尚未执行的项目始终标记为待验收。

## 展示模式

**`world-state.ts`** — 新增展示模式的作息模型
- `WorldState.showcase` 布尔字段（默认关闭，只有存过布尔值才恢复，损坏存储回到默认）。
- `daylightAt(hour)`：把渲染器原来的日照公式抽成可测试的纯函数，渲染和作息共用同一份太阳高度。
- `showcaseAt(hour, season, weather)`：一天的作息分段——深夜安睡 → 起床 → 晨间 → 上午工作 → 午休 → 下午工作 → 傍晚回家 → 夜间 → 深夜阅读 → 准备睡觉。返回该时段应开哪些设备。
- **夜间灯独立于作息**：路灯、串灯、熔岩灯只看天色 `daylight < 0.35`（约 17:57 亮、06:08 灭），所以天黑后一直亮到天亮，包括深夜和熟睡时段。
- 暖炉/风扇/窗户按季节与天气推导（冬季在家时段取暖、夏季午后风扇、非冬季白天开窗、雨雪雾关窗）。

**`index.html`** — 时刻滑块下方按钮栏新增 `展示模式` 按钮（`#showcase`，带 aria-pressed 与悬停说明）。

**`main.ts`** — 展示模式接线
- 开启时自动启动「时间流动」（并记住是谁开启的，关闭时还原）。
- 每帧调用 `applyShowcase()`，仅在该时段切换时应用一次，所以同一时段内手动改动会保留到下一段。
- 串灯接管：开启时强制 `cycle`（自动变色）+ `chase`（顺序点亮），节奏为 0 时补 1 圈/秒；关闭时**还原用户原来的串灯设置**。
- 状态栏播报每一段的变化，例如 `20:01 · 夜间 · 开启顶灯、熔岩灯、串灯、路灯、Mac 屏`。

**`style.css`** — 展示模式按下态高亮；窄屏下按钮栏允许换行。
