风扇增加摇头与按键指示：扇头用自身的 Blender 枢轴 ANIM_fan_head 做偏航摆动（不修改模型，与扇叶旋转同一层运行时动画），慢档约 11 秒、快档约 8 秒一个周期，摆幅 ±0.5 / ±0.62 rad，停下时缓回中位；摇头不做成开关，只要 fanSpeed > 0 就摆，因此 WorldState 去掉了 `fanOscillate` 字段（旧存档带着它也能加载，字段被忽略）。底座三颗按键各持私有材质（与 200+ 道具共用 MAT_P2_Cream / MAT_P2_Terracotta，故从静态合并排除，代价 +3 绘制调用），停时最右红、慢时最左、快时中间，展示模式夏季午后开风扇时同样摆头。这里踩过一个坑：GLTFLoader 会删掉节点名里的点，Blender 的 `Fan_BaseButton.001` 到达运行时变成 `Fan_BaseButton001`，原来的排除正则写成 `\.\d+` 于是只放行了最左一颗，另两颗被并进静态合批、材质被忽略而不亮；改为 `Fan_BaseButton[\d.]*` 后三颗都能各自点亮（已用渲染像素核对：停档右键 rgb 207,134,113，慢档左键 rgb 208,206,157，快档中键 rgb 207,209,143）。

控制面板的移动端自适应：根因是 `.console` 的 `max-width:calc(100% - 32px)` 相对自身计算（父级 .dock 宽度由内容决定），462px 的面板在 390px 手机上实际渲染成 430px 宽并向左溢出到 x=-36，把同一 dock 里的圆环也带出屏幕（只剩 20px 可见）。改成 `calc(100vw - 32px)` 并按视口定宽（手机 = 100vw-24px）后实测回到 12..378；手机上面板改为上下顺序反转（column-reverse）让圆环落在面板下方，避免面板盖住唯一的开合入口；`.console-title` 留在面板框内、只有 `.console-body` 滚动，所以拖动把手与 ⟲ 复位始终可点——这里又踩到一个坑：`.dock.open>.console{display:block}` 的优先级压过 `.console{display:flex}`，面板不是 flex 容器，body 就无法收缩，设置内容会溢出面板底部 428px，改为 `display:flex` 后 body 才在面板内滚动（468px 内滚动 792px 内容）。触屏下开关放大到 42×24、行高 34、面板按钮 38（`@media(pointer:coarse)`），并用 `env(safe-area-inset-bottom)` 让开手机手势条；竖屏与横屏（≤520px 高）分别限高，横屏时面板宽度收敛到 min(440px,60vw)。
