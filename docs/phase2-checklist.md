# Phase 2 制作与验收清单

2026-09-06，用户授权进入 Phase 2，并将 Phase 1.5 的五项问题一起修正交付。当前仅完成范围记录；Blender MCP 连接检查无可用实例，尚未修改模型。

## 必须修正

- 建模精细度：Mac、CRT、电话、耳机等英雄道具补齐可辨识轮廓、结构接缝、按键、孔位、支撑与接触细节，不能只靠上色掩盖盒子占位。
- 桌面秩序：保留生活故事与既有资产位置需求，按电脑操作区、通信区、随手物品区整理；键盘鼠标保留使用空间。电话线两端真实接到设备上，盘线缩短并自然落在桌面；耳机补齐头梁、转轴与耳垫，放置方式明确，线缆不再像独立弹簧。
- 穿模：逐区检查桌面、设备背部、椅背、被子、床边设备、窗台和植物。检查真实接触、支撑、线缆路径与移动部件的间隙；区分必要装配接触和意外穿插。
- 绿植：将脱离房间的前景盆栽放回有支撑的位置，盆底落地；重做有叶柄、弯曲中脊、厚度和自然朝向的叶片，避免大块多面体叶子及茎叶脱节。
- 猫：重做可辨识的猫形，明确耳朵、口鼻、脸颊、前后爪、蜷卧脊背和尾巴，使用柔和曲面与低饱和毛色；猫体落在猫窝中，近景和主机位均能辨认。

## Phase 2 整体范围

保留两墙一地、窗下桌、右侧床与左前 CRT 的总体布局。按美术方向精修房间、家具、设备、织物、纸品、植物与窗外道具，使用统一低饱和色板和 Principled BSDF 材质。保持 INT_ / ANIM_ / EMIT_ / SOCKET_ / SEASON_ 契约。季节物件应检查各自位置与遮挡，后续动态切换仍属于 Phase 4。

Phase 3 的 UV/光照烘焙与 Phase 4 的屏幕内容、天气、交互不算本轮已实现功能。屏幕测试卡继续用于角度和可读性检查。

## 交付验收

1. 先保留 Phase 1.5 源文件备份，再修改当前项目；不触碰其他项目模型。
2. 每批完成后检查视口与局部近景，有明确问题就修改后重新检查。
3. 输出整体黄昏、整体深夜、桌面近景、猫与植物近景，避免仅凭远景验收精细度。
4. 报告具体修复了哪些穿插、桌面哪些物件移位及其原因，更新资产清单。
5. 保存 blender/lofi_room.blend，唯一 scripts/export_glb.py 导出；核对最终应用修改器后的三角面 <80k、正缩放、法线、独立角色与挂点。
6. 网页刷新检查昼夜和三个机位、材质、屏幕、Console；构建及 GLB 契约检查通过。报告实际绘制次数，不以构建成功替代视觉与性能验收。
7. 结束释放 Blender 控制权。
