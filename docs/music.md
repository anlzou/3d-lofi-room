# 窗边留座 / Window Seat

原创程序作曲，76 BPM，32 小节，约 101 秒，立体声循环。电钢琴式加音和弦、短句旋律、低音、带轻微 swing 的鼓组，未使用第三方歌曲、录音或采样。源代码 `scripts/compose_bgm.py`，音频 `public/audio/window-seat.wav`。可随本项目分享。

音频峰值 0.72，RMS 约 0.140，无数字削波；尚未进行独立人工听感评审。合成音色与商业录音有区别，后续可根据实际试听调整。

音乐默认关闭，在“房间里的小事”中点“播放窗边留座 ♫”；与环境底噪可分别开启，共用音量。M 切换静音。网页或应用进入后台暂停，返回后恢复用户此前开启的音乐。存储设置不会自动播放音乐。
